# Ward Flow lessons — historical repository copy

This directory preserves lessons imported during the former Database workflow.
It records their committed wording; it does not establish current authority,
completeness, sanitisation or clinical approval. Recheck facts against current
Ward source before using a lesson.

## Private importer retired — 2 October 2026

The former Database memory store is private and belongs to another project.
`node scripts/ward-flow/sync-lessons.mjs` and its `--check` form now refuse without
reading that store or writing files. Do not use them as generation/freshness gates.
Existing historical lessons remain intact; no private contents were inspected for
this repair. This correction does not establish that an earlier leak occurred.

New maintained guidance belongs in the appropriate Ward-owned document after
source ownership and sanitisation review, not in an unrelated private importer.
