## Acceptance boundaries

- Preserve existing clinical decisions, physical-arrival conflict recording, synthetic-only and typed-text browser-storage boundaries.
- Never weaken a test, threshold, ownership guard or required verdict to pass.
- For upstream braces, install a supported patch if available; otherwise prove the retained mitigation and state explicitly that the upstream advisory is still open. No forced unsupported downgrade.
- Link release journeys into the existing required aggregate; no live branch-protection change is necessary.
- Use a disposable loopback database for real-store integration, with no provider credentials or live services.
- Capture red/green evidence for code fixes. Documentation and generated manifest corrections use their actual checkers.
- No design overhaul. Preserve the existing layout and shared components.
