Rule 1: Placement & Hierarchy by Page Class

Class A: Network Coordinator Views (Command, Delays, Capacity, Movements, Referrals)
The title displays the view name (`Command`), and the badge displays the active health service filter (`STATEWIDE`, `EAST METRO`, etc.). Clicking the badge opens the switcher to filter all lists on the page.

Class B: Specific Inpatient Wards (e.g. Ward 2K, Ward 4A, Graylands)
The title displays the exact unit name (`Ward 2K`). The badge anchors the unit to its permanent parent health service (`EAST METRO`). This reinforces clinical geography for cross-ward transfers.

Class C: Emergency Departments & Teams (e.g. FSH ED, Albany Team)
The title displays the facility name (`Fiona Stanley ED`), and the badge displays the parent jurisdiction (`SOUTH METRO` or `WACHS`).

Class D: Patient-Specific Screens (Patient Now)
The title displays `Patient Now`. The badge displays the admitting hospital's health service scope.

Rule 2: Geometry & Baseline Alignment

Exact 36px Height Lock:
The cockpit capsule has an exact height of 36px (`padding: 4px 6px 4px 14px`), perfectly matching the search box and drawer buttons. This guarantees an unbroken horizontal horizon across the entire top bar.

Zero External Subtext:
No secondary subtext is allowed below the capsule. Removing the subtext eliminates vertical crowding and allows the top bar to remain a clean, unified single deck.

Responsive Horizontal Constraints:
On desktop viewports, the title dynamically expands up to 32rem to comfortably display long hospital and unit names (such as "Peel Health Campus Emergency Department" and "Sir Charles Gairdner Hospital Emergency Department") without truncation, gracefully applying ellipsis if screen space is constrained. On mobile (390px), the title wraps cleanly while the badge compacts.

Backend Architecture & Token Layer

The backend color key module is implemented at src/components/ward-management/ward-service-colors.ts, providing:

• Full metadata: Legal names, brand hex codes, facility mappings, and contrast ratings.
• Token mapping: Directly bridges into ward-flow-shell-tokens.module.css.
• Type safety: Strict TypeScript contracts ensuring no health service can go missing or unstyled.
• Runtime helpers: getHealthServiceBadgeStyle() and getHealthServiceDotStyle().

Accessibility & Keyboard Navigation (WCAG AA & AAA)

Accessible Name & Role:
The scope badge is a semantically native <button type="button"> with aria-haspopup="true" and aria-expanded state.

Contrast Proof:
Every service tint achieves 7.0:1 to 8.5:1 contrast against its background, exceeding both WCAG AA (4.5:1) and WCAG AAA (7:1) requirements.

Keyboard Contract:
Pressing Enter or Space opens the menu. Pressing Escape dismisses it cleanly and returns focus to the trigger.
