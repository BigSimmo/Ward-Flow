# Ward Flow records kept from PsychSift's issue and review systems

On 26 September 2026 Josh approved retiring PsychSift's issue list, its issue inbox, its branch
review records and the tools that read them ("Yes all" in the Remove PsychSift leftovers thread).
Ward Flow never used those systems; it keeps its own task ledger in `docs/ward-flow-task-ledger.md`.
Before they went, every record about Ward Flow was moved or copied here, word for word:

- `outstanding-issues-inbox/`: the 102 inbox requests about Ward Flow, in their original layout
  (`applied/` included), with the inbox README that explains their format. This includes the 28
  requests Owner Ruling 14 kept "for permanent audit preservation"; they are still kept permanently,
  now here.
- `outstanding-issues-ward-rows.md`: the 37 rows about Ward Flow from PsychSift's issue list.
- `branch-review-records/`: the 20 review records that concern Ward Flow (18 Ward Flow branches and
  2 mixed reviews that touched it), with the records README and `branch-review-archival-policy.md`.
- `review-log-ward-rows.md`: the lines about Ward Flow from the review logs and their index.

Everything else those systems held is in git history: backup branch
`backup/2026-09-26-psychsift-records-pre-retire`, and on `origin/main`, where PsychSift still runs.
These files are history; nothing reads or checks them.
