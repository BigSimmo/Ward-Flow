# Which screens have a drawing, and which do not

**The owner's own inventory, given 2026-09-09, recorded here because it existed only in a chat.**
A drawing that lives only in the conversation that made it is the same failure as a document that
lives only on one branch — and that has caught this programme four times in two days. Where a name
below is the owner's, it is his word for the drawing, not a file path.

⚠️ **This is an inventory of DRAWINGS, not of built screens.** A screen can be built with no drawing
(Delays) and drawn with nothing built (CMHT statistics, until 2026-09-08).

## ⚠️ How this squares with the third edition, and it does not

`WARD-FLOW-DESIGN-SYSTEM.md` (third edition, merged as PR #2738) indexes **twelve** screens:
Command, Movement, Capacity, Wards, Emergency departments, Community teams, Patient search,
Referrals, Handover, Statistics, Governance, Raise a referral.

**Set against the inventory above, the third edition's twelve do not include:**

- 🔴 **Delays** — the one screen the owner personally locked and reviewed, and the one whose own
  drawing is in no branch of this repository.
- 🔴 **New patient** — the owner's first priority, and the front door of the whole system.
- **Discharges**, **Transport officer**, **Out of area**, **Network diagram**, **Bed board**, and the
  **Ward Flow entry page**.

It does cover **Handover** (its screen 9), which is the owner's second priority — so that gap is
closed by the third edition and the first one is not.

**This is a scope observation, not a defect in the third edition.** Twelve may be the right twelve.
But a standard that indexes twelve screens, in a system with fifteen or sixteen drawn and roughly
twenty-two real pages, is a standard with a documented edge — and the screen sitting outside it is
the one the owner locked.
