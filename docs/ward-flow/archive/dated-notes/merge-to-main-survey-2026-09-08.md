### 3.1 The 85 are mechanical — proven, not assumed

For each of the 85, `origin/main`'s blob for that path was searched against every blob that path
has ever held in this branch's history:

```
OURS-STRICTLY-NEWER (main's blob is a past state of ours): 85
GENUINELY DIVERGENT (main's blob never existed here):       0
```

⚠️ **The first pass of this check reported 11 divergent, and all 11 were an artefact.**
`git log --raw` shows no diff for a merge commit unless asked. This branch is built from folds, so
blobs introduced by a fold resolution were invisible to it. Re-run with `--diff-merges=separate`,
all 11 resolved to _contained-after-all_. **Any repeat of this measurement must pass
`--diff-merges=separate`, or it will over-report divergence and manufacture false decisions.**

So on these 85, `main` holds an older state of our own file and nothing else. Taking this branch's
side is a mechanical merge, not a choice about behaviour.

MATTERS MOST.** On this machine MSYS rewrites a leading-dot pathspec:

```
$ git rev-parse "origin/main:.github/workflows/ci.yml"
fatal: ambiguous argument 'origin\main;.github\workflows\ci.yml': unknown revision or path…
$ MSYS2_ARG_CONV_EXCL="*" git rev-parse "origin/main:.github/workflows/ci.yml"
```

right about 96 paths and silently wrong about the one that is hardest to merge. **Set
`MSYS2_ARG_CONV_EXCL="*"` before any such loop, and account for unresolved paths explicitly rather
than `|| continue` — a skipped path and a clean path look identical in a counter.**
