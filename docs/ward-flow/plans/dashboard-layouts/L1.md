## Responsive and print behavior

- New fixed/max heights are desktop-only (`min-width: 62.5625rem`, with the two noted existing-grid breakpoint adjustments). Phone and narrow tablet layouts therefore keep natural document scrolling.
- Every affected stylesheet has a later `@media print` release for the new height, max-height and overflow boundaries. Existing print-only visibility decisions remain intact; content inside every new bounded body is no longer clipped by L1 containment.
- The local declarations use the shared `--ward-workspace-height`, `--ward-section-height`, `--ward-compact-height` and `--ward-sticky-top` variables, with the plan’s literal clamps as fallbacks.
