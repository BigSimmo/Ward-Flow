  - Added a route-derived role card using distinct coordinator, ward and ED icons and existing derived navigation counts.

  - Preserved the full-height sticky desktop rail and provided compact icon controls for the closed rail plus a wrapping mobile treatment.

## Truth and scope boundaries

- Ward Flow has no authenticated session and therefore no real sign-out action. The rail keeps the existing truthful destinations: `Sign-in demonstration` and `Exit to developer hub`; it does not label either as sign-out.
- `Live tally` means the current in-memory synthetic state. The drawer labels the state synthetic and shows demo time; it does not claim a live provider connection.
- Notice text and audience remain reducer-owned. This task only filters and renders the provider's read-only notice collection.
- Task drawer behavior and engine/provider mutation behavior were not changed.
