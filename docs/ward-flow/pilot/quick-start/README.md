# Pilot quick-start sheets

For: staff starting the shadow pilot, and the trainers who hand these out. Status: current.
Owner: pilot lead (to be named).

_Updated 2026-11-08 - one sheet per desk, drawn from the desk guides and source at `d85618e6`;

One printed page for each desk. Each sheet says what the desk uses Ward Flow for, how to sign in,
the most common tasks, what not to use it for and who to contact. The tasks match the
[competency check](../competency-check.md) done before an account goes live.

## Keeping them true

- The longer [desk guides](../../desk-guides/README.md) are the source for these sheets. When a
  desk guide changes, change the matching sheet in the same change.
- Use the app's own words for buttons and screens. Keep each sheet to one printed page.
- Never add real patient details, risk scores, suggested wards or computed legal times.

_Prototype on synthetic data. Not for real patients._
