# Data minimisation: field by field

_Created 2026-11-10 - audit item M57 (sources B65, C11), for go/no-go row P3; drafted from source on branch `claude/project-thread-bnphlk` (from `main` `29352cd0`); Documentation owns._

**Status:** draft for the privacy officer. **Not approved.** Go/no-go row P3 stays open until the
privacy officer approves the list and the [permission matrix](../permission-matrix.md) enforces
it. This page changes no code and removes nothing.

**Names stay in full.** D-83 keeps patient names on every screen, print and TV view. This page
never proposes removing them. Downloads carry no names (D-102). The question here is only the
fields shown **besides** the name.

**Evidence limit.** Fields come from the `Patient` type (`src/components/ward-management/ward-patients.ts`)
and the record-only list `RECORD_DETAIL_FIELDS` (`ward-shared-record-detail.ts`). Which screen
shows which field was read from source and the desk guides, not walked screen by screen. A person
must confirm each "shown in" cell on the built screens before approval.
