# Archived documents

These are historical Ward Flow and PsychSift-era planning, handover, ruling and process documents
that used to sit at the top level of `docs/`. They were moved here on 4 October 2026 so new sessions
start from the current entry points instead.

**Do not follow them as current guidance.** Start from [`docs/ward-flow/README.md`](../ward-flow/README.md),
[`docs/ward-flow/HOW-WE-WORK.md`](../ward-flow/HOW-WE-WORK.md) and
[`docs/ward-flow/STATUS.md`](../ward-flow/STATUS.md). Current decisions live in
[`docs/ward-flow/decisions.md`](../ward-flow/decisions.md).

A file was archived only when no code, script, test or configuration referred to it. Links to
these files elsewhere in the repository were updated to point here. Full history is in Git.
